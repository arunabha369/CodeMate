# facts.md — Phase 1 fact check

Checked: 2026-10-31.

**How this was checked.** This cloud session's network policy blocks en.wikipedia.org, wikidata.org, en.banglapedia.org and the museum sites, so no source page could be opened directly. Every check below comes from web-search results: the search engine quotes and summarises the source pages. The sources are named on each row. Rows marked *standard* are uncontroversial basics of the story that weren't searched one by one. Once the domains are allowed, re-open the pages for anything marked UNVERIFIED or `pending`.

Status key: **VERIFIED** = the sources agree with the script line as written · **CONFLICT** = the sources disagree with the line, or with each other in a way the line ignores · **UNVERIFIED** = couldn't be confirmed.
