# Voice lines for ElevenLabs (65 clips)

Make **one audio clip per scene**. Copy the text in each box into ElevenLabs, generate it, download it, and rename the file exactly as shown (`S01.mp3`, `S02.mp3` … `S65.mp3`).

**Keep these the same for every clip:**

- the same voice and the same settings (stability, similarity, speed);
- a model that supports Bengali (for example **Eleven v3**);
- no music or sound effects in the clip.

Silence at the start and end is trimmed automatically.

If a word sounds wrong, you can re-generate just that clip. Numbers are already written as Bengali words, so the voice reads them correctly.

**When all 65 files are ready, send them in one of two ways:**

- **Easiest:** put all 65 MP3s into one `.zip` file and attach it here in the Claude chat.
- **Or on GitHub (desktop browser):** put the files in a folder named `vo`. Open https://github.com/arunabha369/CodeMate/upload/claude/modest-heisenberg-gs9wem/explainer-video/howrah-bridge/project/public, drag the whole `vo` folder onto the page, and click **Commit changes**.

Then type **"done"** in the chat.
