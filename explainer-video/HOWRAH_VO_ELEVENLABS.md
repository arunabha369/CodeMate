# হাওড়া ব্রিজ কীভাবে তৈরি হলো — ElevenLabs narration

The text below is copied exactly from `HOWRAH_SCRIPT_BN.md`: 53 clips, about 1,300 words, which comes to about 9–10 minutes.

## ElevenLabs settings

| Setting | Value |
|---|---|
| **Model** | One whose language list includes **Bengali**. *Eleven v3* does; if your account shows Bengali for another model, that works too. |
| **Voice** | A warm, confident documentary narrator. Try S01 (the hook) in 2–3 voices first, then use the **same voice and settings for every clip**. |
| **Stability** | ~45–55% (v3: *Natural*) |
| **Similarity** | ~75–80% |
| **Style** | ~20–35% |
| **Speed** | 1.0 to start; use 0.95 if the total is under 9:00, or 1.05 if it is over 10:00 |
| **Output** | MP3, 44.1 kHz |

## How to generate

1. Generate **one clip per scene** and save it as `S01.mp3`, `S02.mp3` … `S53.mp3`. Short clips give cleaner pacing, easy retakes, and let every animation sync to its own clip.
2. Copy each block exactly as written. The `।`, `,` and `—` marks create the natural pauses, so don't add extra dots or line breaks.
3. Listen to S01–S04 before doing the rest. If a word sounds wrong, respell it phonetically in Bengali, keep the change in both files, and regenerate that clip only.
4. Make the hook (S01) the best take: confident, slightly slower, with a short pause at `—`. With Eleven v3 you can try an emotion tag such as `[curious]` at the start of S01, but test it, and remove the tag if it is read aloud.

## After generating (with the Remotion project from this repo)

Copy `HOWRAH_SCRIPT_BN.md` into the project as `SCRIPT_BN.md` (next to `project/`), then run:

```bash
npm run parse
```

Put the clips in `project/public/vo/`, then measure them:

```bash
python3 tools/make_vo.py --engine files
```

Then render:

```bash
npm run render
```

If you have an ElevenLabs **API key**, the project can generate every clip automatically instead:

```bash
ELEVENLABS_API_KEY=... python3 tools/make_vo.py --engine elevenlabs --voice <VOICE_ID> --model eleven_v3
```

With Claude Code and `HOWRAH_BRIDGE_PROMPT.md`, just tell it the clips are in `public/vo/` (or give it the key) and it will skip TTS and time everything to your audio.
